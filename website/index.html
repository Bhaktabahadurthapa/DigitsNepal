⚡

Live as you type

English appears while you write — on a pause or at the end of a sentence. No translate button needed.

Private by design.

DigitsNepal never runs in the background reading what you type. It only sees text you type into it or explicitly select and send with the shortcut.

  • No account, no analytics, no telemetry
  • Text goes only to the AI provider you choose — local by default
  • Cloud providers require your explicit opt-in, one by one
  • API keys live in the macOS Keychain, never in files
  • Password fields are never read; history is off by default
  • Open source under the MIT license — audit every line

Download DigitsNepal

Version 0.1.0 · free · macOS 12 or later

⬇ Download for Mac (.dmg) Build from source
  1. Open the .dmg and drag DigitsNepal into Applications.
  2. The first time, right-click DigitsNepal → Open, then click Open (early builds aren't notarized by Apple yet).
  3. In Settings › AI provider, choose a provider and model — then just start typing.
  4. For the shortcut in other apps, allow DigitsNepal under System Settings › Privacy & Security › Accessibility.

Translation quality depends on the AI model you choose. Always review important messages before sending.
