# digitsnepal.com

Static site — "interlinear manuscript" design. No build step, no third-party requests.

- `index.html`, `site.css`, `site.js` — page, styles, interlinear demo + reveals
- `fonts.css`, `fonts/` — self-hosted Rozha One, Mukta, IBM Plex Mono (SIL OFL 1.1; latin + devanagari subsets)
- `paper-light.webp`, `paper-dark.webp` — seamless lokta-paper textures (generated)
- `.htaccess` — HTTPS redirect, caching, security headers

Deploy: upload the folder contents to Hostinger `public_html` (see docs/RELEASE.md).
